# Maintainer review

Start with tinybuilder-onboard. Inspect actual diffs, exact-head checks and
latest evidence rather than PR descriptions alone. Compare options against the
mission, total resource cost, reliability, maintainability, licensing,
privacy and release scope. Classify each decision adopt/adapt/defer/reject;
state rationale, alternatives and what evidence could reverse it. Distinguish
proposal from accepted direction and CI from live qualification. Do not merge,
tag or publish without authorization. Record actionable next steps and use
tinybuilder-knowledge-maintenance.
