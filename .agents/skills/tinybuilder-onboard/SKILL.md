# Onboard

Read [AGENTS.md](../../../AGENTS.md), [Agent guide](../../../docs/AGENT_GUIDE.md)
and [Project status](../../../docs/PROJECT_STATUS.md). Inspect current main, open PR
heads, ancestry, CI and (locally) worktrees and dirty files. Check accepted
decisions and latest research evidence; unmerged docs are labeled as such.
Identify product vs lab scope, active owner, reusable existing implementation,
and the smallest next measurable task. Choose a task-specific skill. Do not
duplicate active Codex work. If a connector is unavailable, use the available
checkout, label unknown status and request only necessary missing evidence.
For a simple question, avoid a full repository scan. Close substantive work
with [knowledge-maintenance](../tinybuilder-knowledge-maintenance/SKILL.md).
