Qwen2.5-Coder models **did not perform a verified inspection or Laravel edit**.

inference, system installation or production-project access occurred.

These are individual observations, not controlled latency comparisons. Model
loading, warm prompt caches, memory pressure and model eviction affected timing.
Each smoke fixture had a randomly generated package name that was absent from
the task and system summary. Neither required model identified both facts
correctly, and neither called `read_file`. Successful native calls: **0**; tool
argument accuracy cannot be estimated with zero calls.

An observed 1.5B response printed this as ordinary assistant text:

```json
{"name":"read_file","arguments":{"path":{"type":"string","description":"Subdirectory relative to project root; use '.' for root"}}}
```

It was enclosed in a Markdown JSON code fence and lacked a native `tool_calls`
field. Even explicit tool-call-format reminders and a one-tool-only direct HTTP
probe produced text examples. In the one-tool probe, 0.5B invented the name
`read_composer_json`, 1.5B supplied an object instead of a string path, and 3B
supplied `/path/to/composer.json`. Additional direct 1.5B probes with required
and named tool choice also returned ordinary text. These were diagnostic
variants, not counted as successful benchmark trials.

`--verbose` confirmed the distinction:

```json
{"event":"model_start","step":1}
{"event":"model_end","step":1,"tool_calls":0,"duration_seconds":0.672}
```

No fallback converted prose or fenced JSON into executable actions. The observed
blocker is stock-model/native-tool-protocol behavior in this Ollama setup; it is
not an HTTP connectivity failure. This does not establish a universal inability
of these models, nor performance with other templates or inference servers.

## Changes, reproduction and remaining work

Added sanitized opt-in tool events, an exact-argv execution restriction, the
disposable-worktree evaluation harness and regression coverage. Preserved the
standard-library runtime, explicit memory design and isolated training setup.

Setup fixes: use the existing real Python interpreter rather than the Microsoft
Store alias; prepend Herd's `php85` executable directory to process PATH rather
than enabling a shell; disable expensive Composer optimized autoload generation
in the disposable fixture. No system settings were changed.

claim model-driven Laravel capability or start training based on this failed trial.
