## Implemented source / decisions

Stages A/B initial standalone crate: strict typed request/observation/identity/limits, explicit trusted-control scope and unqualified outer record, deny candidate admission by construction, exact worker identity and policy validation on both sides, fail-closed result attribution and supervisor/worker split. Fixed reviewed hand-authored WAT controls; no arbitrary input. See [lab README](../../lab/portable-evaluator/README.md). The 12 controls include positive return, WASIp1 no preopen/path/env/args/socket descriptor, missing host spawn import, positive/negative guest memory, fuel, epoch and native watchdog. These are narrow model-free probes, not the full research security matrix. Failures/blocks are not semantic scores. Guest memory cap two pages, fixed 100,000 fuel, 30-second normal deadline and 5-second ready/sleep watchdog are deliberately tiny proof-of-concept limits, not calibrated Laravel requirements.

Source-verified tagged workspace/license and upstream advisories, no complete transitive clearance. The separate workflow shares one resolved lock across Windows x64/macOS ARM64/Linux x64; the first resolution is explicitly bootstrap, not reproducible across runs until the lock is reviewed and committed.
